# Portfi — AI Portfolio Builder

Portfi is a modern, privacy-first portfolio builder engineered for top-tier professionals. Build, preview in real time, and export production-ready standalone HTML portfolios without framework bloat or server dependencies.

For complete architectural details, technology breakdown, and deployment notes, refer to [DOCUMENTATION.md](file:///Users/rumaispp/Documents/pportfolio%20builder%20/DOCUMENTATION.md).

## Getting Started

### Prerequisites
- Node.js 20+
- npm, pnpm, or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Build
```bash
npm run build
npm start
```
